# MyTerm 使用手册

> 适用版本：**0.2.1**

MyTerm 是一个 Windows 桌面终端模拟器，本手册按 *启动方式 → 界面操作 → 快捷键 → 使用场景* 的顺序组织。

---

## 1. 启动方式

### 1.1 安装包启动（推荐普通用户）

到 [Releases](https://github.com/YOliver/MyTerm/releases) 下载 `MyTerm-Setup-<version>.exe` 双击安装：

- **安装位置**：`%LOCALAPPDATA%\Programs\MyTerm\`（用户级，**无需管理员权限**）
- **启动入口**：开始菜单 → MyTerm

### 1.2 绿色版 EXE

下载 `MyTerm.exe` 单文件版，放任意目录双击运行，不写注册表。

### 1.3 源码启动（开发者）

```bash
git clone https://github.com/YOliver/MyTerm.git
cd MyTerm
pip install -r requirements.txt
python main.py
```

> 开发模式下 `shell_presets.json` / `path_history.json` 落在工程根，便于调试；打包模式会写入 `%LOCALAPPDATA%\MyTerm\`。

### 1.4 命令行启动（带参数）

主程序入口 `main.py` 透传 `argv` 给 Qt，可按 Qt 应用通用参数启动（`-style fusion` 等）。

## 2. 启动一个终端

启动后窗口分三层：

1. **菜单栏**：环境（依赖检测）、Skills（技能浏览）、设置（AI CLI 配置 / CLI 安装）、日志、帮助（使用说明 / 软件信息）
2. **顶部工具栏**：工作目录下拉、Shell 预设下拉、浏览、启动
3. **终端网格区**：底部主体，启动后在此显示终端

### 最短路径

1. 在路径下拉框选历史目录，或点「浏览」选新目录（路径会自动加入历史）
2. 选 Shell 预设（默认 `powershell` / `cmd`）
3. 点「启动」

每个终端 tile 顶部显示「目录名 + Shell 标签」，右上角 × 关闭。

---

## 3. 菜单栏功能

### 3.1 环境

- **检测依赖**：一键检查本机 Node.js / npm / Python / Git 安装状态与版本
  - 显示版本号、可执行文件路径
  - 未安装或调用超时会有相应提示

> AI CLI（claude / codebuddy 等）不在此处检测——能不能跑起来在启动下拉框里点一下就知道。

### 3.2 Skills

- **Skills 浏览**：查看各 CLI 工具（Claude Code、CodeBuddy、Codex、Gemini、Qwen）已安装的全局 skills 清单
  - 点击 skill 名称选中（蓝色高亮）
  - 「查看 SKILL.md」预览 skill 完整内容
  - 「打开 Skills 目录」在资源管理器中打开对应文件夹

### 3.3 设置

- **AI CLI 配置**：可视化管理「Shell 预设」（标签 / 宿主 / 命令三列表格）
- **CLI 安装**：内置 5 家 AI CLI 安装脚本，菜单点一下就装好
  - Claude Code (`@anthropic-ai/claude-code`)
  - CodeBuddy Code (`@tencent-ai/codebuddy-code`)
  - Codex CLI (`@openai/codex`)
  - Gemini CLI (`@google/gemini-cli`)
  - Qwen Code (`@qwen-code/qwen-code`)

  装完自动追加进启动下拉框，卸载时自动回收。

### 3.4 帮助

- **使用说明**：就地查阅本手册
- **软件信息**：查看版本号、commit、依赖
- **日志**：打开当前会话日志目录

## 4. AI CLI 配置详解

下拉框里出现哪些 shell / AI CLI，完全由你自己配置。新装时只默认两条 `powershell` / `cmd`，其它按需自己加，新装一个 AI CLI 不用等软件升级。

### 4.1 入口

菜单栏 **设置 → AI CLI 配置...**

### 4.2 字段说明

| 字段 | 含义 |
|------|------|
| **标签** | 启动下拉框里显示的名字，也用来在保存后回填上次的选择 |
| **宿主** | 三选一：`powershell` / `cmd` / `none`，决定外层怎么包裹你的命令 |
| **命令** | 在宿主里要执行的命令 |

### 4.3 宿主选哪个

| 你的 AI CLI 长啥样 | 宿主 | 命令填什么 |
|------|------|------|
| npm 全局装的（`claude`、`codebuddy` 这种 .cmd 命令） | `powershell` | `claude` |
| 想跑带参数的（如 `claude -r` 续接最近会话） | `powershell` | `claude -r` |
| 习惯在 cmd 下跑 | `cmd` | `codebuddy` |
| 直接启个 shell 本身（bash、wsl、pwsh 等） | `none` | `bash.exe` 或 `wsl.exe` |

底层规则：

- `powershell` → 自动包成 `powershell.exe -NoExit -Command <你的命令>`
- `cmd` → 自动包成 `cmd.exe /K <你的命令>`（用 `/K` 不是 `/C`，命令跑完会保留 cmd 会话不闪退）
- `none` → 直接当 argv，用 Windows 风格分词，**带空格的路径要用双引号包住**，例如：`"C:\Program Files\Git\bin\bash.exe" --login`

### 4.4 操作按钮

- **新增**：在选中行下方插入一行，自动进入编辑（默认值是 `新预设 / powershell / 空命令`）
- **删除**：删选中行（至少保留一条）
- **↑ / ↓**：调整顺序，顺序就是启动下拉框里的顺序
- **保存**：写盘 + 立即刷新主窗口下拉框，**已开的终端不受影响**
- **取消**：全部丢弃，不写盘

### 4.5 常用配置示例

```
标签              宿主         命令
─────────────────────────────────────────────────
powershell        none         powershell.exe
cmd               none         cmd.exe
claude            powershell   claude
claude -r         powershell   claude -r
codebuddy         powershell   codebuddy
gemini            powershell   gemini
git-bash          none         "C:\Program Files\Git\bin\bash.exe" --login
wsl               none         wsl.exe
```

### 4.6 配置文件位置

`%LOCALAPPDATA%\MyTerm\shell_presets.json`，JSON 结构：

```json
{
  "version": 1,
  "presets": [
    {"label": "claude", "host": "powershell", "command": "claude"}
  ]
}
```

文件损坏或字段非法时**不会覆盖你的手改**，会回退到默认两条并在错误日志里给出提示。

## 5. 快捷键

### 5.1 文本操作

| 操作 | 快捷键 |
|------|--------|
| 复制选区（无选区时发送 SIGINT） | `Ctrl+C` |
| 强制复制选区 | `Ctrl+Shift+C` |
| 粘贴（图片自动落盘） | `Ctrl+V` |
| 透传 EOF / SUB | `Ctrl+D` / `Ctrl+Z` |

### 5.2 行编辑（透传给 shell，由 PSReadLine / readline 解释）

| 操作 | 快捷键 |
|------|--------|
| 删除光标前一个单词 | `Ctrl+W` / `Ctrl+Backspace` |
| 删除从光标到行首 | `Ctrl+U` |
| 删除从光标到行尾 | `Ctrl+K` |
| 跳到行首 / 行尾 | `Ctrl+A` / `Ctrl+E` |
| 清屏 | `Ctrl+L` |

> 提示：粘贴含换行的多行文本后，PSReadLine 会把整段当成一行处理，`Ctrl+U` 可能被换行符卡住。此时可按两次 `Esc` 撤销整段输入。

### 5.3 滚动历史

| 操作 | 快捷键 |
|------|--------|
| 上下翻一屏 | `Shift+PageUp` / `Shift+PageDown` |
| 跳到历史顶部 / 底部 | `Shift+Home` / `Shift+End` |
| 滚轮 | 每滚一格滚 1 行 |

历史缓冲保留最近 **2000 行**。

### 5.4 方向键 / 编辑键

- `↑` / `↓`：透传，shell 用来翻命令历史
- `Home` / `End` / `Delete` / `PageUp` / `PageDown`：透传给前台程序（vim、less 等可用）

## 6. 鼠标操作

- **左键拖选**：选中文本（跨行可选）
- **双击**：按非空白字符边界选中一个「词」
- **右键**：有选区时把选区直接发送给终端（不经剪贴板）；无选区时粘贴剪贴板（行为对齐 Windows Terminal）

### 跨终端选区共享

A 终端选中文本 → 在 B 终端右键 → 直接发送 A 的选区文本。

---

## 7. 多终端布局

- 同时最多 **4 个**终端
- 网格自动按数量调整：1 → 1×1，2 → 1×2，3 / 4 → 2×2
- 关闭其中一个会重新平铺，剩下的填满剩余空间

---

## 8. 实时输出与终端兼容

- **PTY 实时输出**：基于 pywinpty + QThread，shell 输出无延迟实时显示，不受输出量影响
- **真彩色 ANSI**：16 色 / 256 色 / 真彩色全部支持，PowerShell 原生配色直接还原
- **2000 行回滚**：历史缓冲自动保留最近 2000 行
- **CJK / 特殊字符**：Braille / Box Drawing / 中日韩等宽字符不串位（基于 wcwidth）
- **中文 IME**：完整支持微软拼音 / 搜狗等输入法，候选框跟随光标

---

## 9. 图片粘贴

剪贴板里有图片（QQ 截图、浏览器复制图片、`Win+Shift+S` 截屏等）时，按 `Ctrl+V` 或右键粘贴会：

1. 把图片以 PNG 格式保存到缓存目录 `%LOCALAPPDATA%\MyTerm\Cache\paste\`
2. 把保存后的文件路径以 PowerShell 友好的格式写入终端

这样可以直接把截图喂给 claude / codebuddy 等支持读图的 CLI 工具。

## 10. 典型使用场景

### 场景 1：日常 PowerShell 操作

启动 `powershell` 预设 → 在工作目录里跑常规命令。

### 场景 2:同时观察多个进程

启动 4 个终端：1 个跑 `npm run dev`、1 个跑 `pytest --watch`、1 个跑 `git status` 循环、1 个常驻 powershell。2×2 平铺一目了然。

### 场景 3：图文喂 AI CLI

启动 `claude` 或 `codebuddy` 预设 → 截图 (`Win+Shift+S`) → 在终端里 `Ctrl+V` → 路径自动写入 → AI CLI 读图。

### 场景 4：跨终端拷代码

A 终端 `cat` 出片段 → 鼠标拖选 → 在 B 终端右键直接粘贴。

## 12. 日志与调试

- **菜单 → 帮助 → 日志**：打开当前会话日志目录
- **日志级别**：默认 INFO，开发模式（源码运行）会同时输出到控制台
- **日志覆盖范围**：PTY 进程生命周期、配置读写、CLI 安装/卸载、异常堆栈

提 Issue 时附上对应时间段的日志能极大加速定位。

## 13. 常见问题

### Q1: 启动下拉框里没有我想要的 AI CLI？

A: 「设置 → AI CLI 配置」自己加一条；或者「设置 → CLI 安装」勾选内置的 5 家自动安装。

### Q2: `Ctrl+C` 没复制反而中断了进程？

A: `Ctrl+C` 在**有选区**时复制，**无选区**时发送 SIGINT。需要无条件复制用 `Ctrl+Shift+C`。

### Q3: 粘贴多行命令被 PSReadLine 卡住？

A: 按两次 `Esc` 撤销整段输入；或者把多行命令保存成 `.ps1` 直接 `.\脚本.ps1` 执行。

### Q4: 中文输入候选框位置错乱？

A: 0.2.0 已修复绝大多数 IME 跟随问题，仍有问题请提 Issue 附上输入法、Windows 版本。

### Q5: 卸载后想保留 / 清除用户数据？

A: 卸载默认保留 `%LOCALAPPDATA%\MyTerm\`，需要彻底清除请手动删除该目录。

### Q6: 装在公司机器上，没有管理员权限装得了吗？

A: 安装包是**用户级**（写入 `%LOCALAPPDATA%`），不需要管理员权限。
