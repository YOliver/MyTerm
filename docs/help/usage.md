# 使用说明

> 本文档介绍 MyTerm 的常用操作。内容待补充。

## 基础操作

- **打开终端**：启动后默认打开一个 PowerShell 终端
- **切换工作目录**：在顶部路径栏选择历史路径，或点「浏览」选择新目录
- **多终端布局**：通过菜单或按钮新建终端，最多 4 个，自动平铺为最接近正方形的网格

## 快捷键

### 文本操作

- `Ctrl+C`：有选区时复制选中文本；无选区时发送中断信号给进程
- `Ctrl+V`：粘贴剪贴板内容；剪贴板内有图片时自动落盘并注入路径
- `Ctrl+Shift+C`：强制复制（即使没有选区也不发送中断）

### 行编辑（透传给 shell）

- `Ctrl+W` / `Ctrl+Backspace`：删除光标前一个单词
- `Ctrl+U`：删除从光标到行首的内容
- `Ctrl+K`：删除从光标到行尾的内容
- `Ctrl+A` / `Ctrl+E`：跳到行首 / 行尾
- `Ctrl+L`：清屏

### 滚动历史

- `Shift+PageUp` / `Shift+PageDown`：上下翻页
- `Shift+Home` / `Shift+End`：跳到历史顶部 / 底部

## 鼠标操作

- **左键拖选**：选中文本
- **双击**：选中单词
- **右键**：有选区时粘选区；无选区时粘贴剪贴板（类似 Windows Terminal）

## 图片粘贴

剪贴板里有图片（QQ 截图、浏览器复制图片等）时，按 `Ctrl+V` 或右键粘贴会：

1. 把图片保存为 PNG 到缓存目录
2. 把文件路径写入终端，方便 claude / codebuddy 等工具读图

## 环境检测

菜单栏 **环境 → 检测依赖** 可查看本机 Node.js / Python / Git / claude / codebuddy 等工具的安装状态与版本。
